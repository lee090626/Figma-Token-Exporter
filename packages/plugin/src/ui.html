Secrets는 어디서 등록하나요?

GitHub 저장소 → Settings → Secrets and variables → Actions → New repository secret에서 FIGMA_TOKEN, FIGMA_FILE_KEY를 추가하세요.

FIGMA_FILE_KEY는 어디에 있나요?

Figma 파일 주소 figma.com/design/여기/파일이름의 가운데 부분이에요.

npx figma-token이 실행되지 않아요

Node.js 18 이상이 필요해요. tokens.json이 명령을 실행하는 폴더(프로젝트 루트)에 있는지도 확인해 주세요.

진행 상황은 이 컴퓨터에 저장돼요. 다시 열어도 그대로예요.
